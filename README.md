## How It Works
Each script maps analog stick flicks to full combo macros:
- **Left Stick** = meterless / no resource combos
- **Right Stick** = meter / super / OD combos

## General Tips
- Always test in Training Mode first with input display on
- Adjust `COMBO_DELAY` if inputs are dropping
- Adjust `THRESHOLD` for stick sensitivity
- Side toggles are built into each script — press **SHARE** to flip
